# Bank Manager System

A console-based banking application written in Java using Object-Oriented Programming. A user creates an account and then deposits money, withdraws money, or checks the balance.

## Features

- Create an account with an account number, holder name, and opening balance
- Deposit money 
- Withdraw money 
- Display account details and the current balance
- Menu-driven interface that runs until the user exits

## OOP Concepts Used

1.Classes and objects
2.Encapsulation
3.Constructors
4.Abstraction

## Project Structure

`project.java` contains the `BankAccount` class and the main program.

## How to Run

Requires the Java JDK.

javac project.java
java project
